單元 03・無線網路應用

DHT11 溫溼度 Wi-Fi 監測

溫度與濕度同步顯示在 16×2 LCD 和手機網頁；Wi-Fi 連線成功時顯示 OK。

步驟 1・準備材料

所需材料與函式庫

ESP32＋擴充板各 × 1
DHT11三腳感應器模組 × 1
16×2 I2C LCD含 I2C 背板 × 1
Wi-Fi 網路手機與 ESP32 使用同一網路

步驟 2・接線

DHT11、LCD 與 Wi-Fi

DHT11 三腳模組

VCC → 擴充板 3.3V 正電源軌

GND → 擴充板 GND 負電源軌

DATA → ESP32 GPIO 4

16×2 I2C LCD 背板

VCC → 擴充板 3.3V 正電源軌

GND → 擴充板 GND 負電源軌

SDA → ESP32 GPIO 21

SCL → ESP32 GPIO 22

注意：確認擴充板電源軌與 LCD 背板規格。ESP32 的 GPIO 不耐 5V；若 LCD 使用 5V 且 I2C 訊號被上拉至 5V，需加雙向電平轉換器。Wi-Fi 使用 2.4 GHz。

步驟 3・上傳程式

完整 Arduino 程式碼

在 Arduino IDE 的程式庫管理員安裝下列函式庫，再填入自己的 Wi-Fi 名稱與密碼。

  • DHT sensor library作者：Adafruit
  • Adafruit Unified Sensor作者：Adafruit
  • hd44780作者：Bill Perry
#include <WiFi.h>
#include <WebServer.h>
#include <DHT.h>
#include <Wire.h>
#include <hd44780.h>
#include <hd44780ioClass/hd44780_I2Cexp.h>

// 請填入自己的 2.4 GHz Wi-Fi 名稱與密碼
const char* WIFI_SSID = "你的WiFi名稱";
const char* WIFI_PASSWORD = "你的WiFi密碼";

#define DHTPIN 4
#define DHTTYPE DHT11
DHT dht(DHTPIN, DHTTYPE);
WebServer server(80);
hd44780_I2Cexp lcd;
float currentHumidity = NAN;
float currentTemperature = NAN;
unsigned long lastReadTime = 0;

void updateSensorAndLCD() {
  if (millis() - lastReadTime < 2000 && lastReadTime != 0) return;
  lastReadTime = millis();
  currentHumidity = dht.readHumidity();
  currentTemperature = dht.readTemperature();

  if (isnan(currentHumidity) || isnan(currentTemperature)) {
    lcd.setCursor(0, 0);
    lcd.print("DHT11 Read Error");
    lcd.setCursor(0, 1);
    lcd.print("Check Sensor    ");
    return;
  }

  // 第一行顯示 Wi-Fi 狀態 OK 和溫度，第二行顯示濕度
  lcd.setCursor(0, 0);
  lcd.print("OK T:");
  lcd.print(currentTemperature, 1);
  lcd.print((char)223);
  lcd.print("C     ");
  lcd.setCursor(0, 1);
  lcd.print("H:");
  lcd.print(currentHumidity, 1);
  lcd.print("%             ");
}

void handleRoot() {
  updateSensorAndLCD();

  String page = "<!doctype html><html lang='zh-Hant'>";
  page += "<meta name='viewport' content='width=device-width,initial-scale=1'>";
  page += "<meta http-equiv='refresh' content='5'>";
  page += "<title>ESP32 溫溼度</title>";
  page += "<body style='font-family:sans-serif;text-align:center;background:#f1f5fb;padding:2rem'>";
  page += "<h1>ESP32 溫溼度監測</h1>";

  if (isnan(currentHumidity) || isnan(currentTemperature)) {
    page += "<p>感應器讀取失敗，請檢查 DHT11 接線。</p>";
  } else {
    page += "<h2>溫度：" + String(currentTemperature, 1) + " °C</h2>";
    page += "<h2>濕度：" + String(currentHumidity, 1) + " %</h2>";
  }

  page += "<p>每 5 秒自動更新</p></body></html>";
  server.send(200, "text/html; charset=utf-8", page);
}

void setup() {
  Serial.begin(115200);
  dht.begin();

  Wire.begin(21, 22);
  int lcdStatus = lcd.begin(16, 2);
  if (lcdStatus) {
    Serial.print("LCD 初始化失敗，錯誤碼：");
    Serial.println(lcdStatus);
  } else {
    lcd.backlight();
    lcd.setCursor(0, 0);
    lcd.print("WiFi Connecting");
    lcd.setCursor(0, 1);
    lcd.print("Please wait...");
  }

  WiFi.mode(WIFI_STA);
  WiFi.begin(WIFI_SSID, WIFI_PASSWORD);
  Serial.print("連線到 Wi-Fi");

  while (WiFi.status() != WL_CONNECTED) {
    delay(500);
    Serial.print(".");
  }

  Serial.println();
  Serial.print("已連線，請在同一 Wi-Fi 的瀏覽器開啟：http://");
  Serial.println(WiFi.localIP());

  updateSensorAndLCD();

  server.on("/", handleRoot);
  server.begin();
  Serial.println("網頁伺服器已啟動");
}

void loop() {
  updateSensorAndLCD();
  server.handleClient();
}

步驟 4・查看溫溼度

LCD 與手機網頁同步顯示

  1. 修改程式中的 Wi-Fi 名稱與密碼，編譯並上傳。
  2. Wi-Fi 連線成功後，LCD 第一行會出現 OK 和溫度，第二行顯示濕度。
  3. 開啟序列監控視窗（115200），查看 ESP32 的 IP 位址。
  4. 手機連上同一個 Wi-Fi，在瀏覽器輸入該 IP，即可查看溫度與濕度。
LCD 顯示初始化失敗時

確認已安裝作者 Bill Perry 的 hd44780，並檢查 SDA → GPIO 21、SCL → GPIO 22；可執行 hd44780_I2Cexp 範例中的 I2CexpDiag 診斷。

Wi-Fi 連不上時

確認使用 2.4 GHz Wi-Fi、SSID 與密碼正確。Wi-Fi 連線成功前 LCD 會顯示 WiFi Connecting；連線成功後才會顯示 OK。

DHT11 讀取失敗時

確認 VCC 接 3.3V 電源軌、GND 接負電源軌、DATA 接 GPIO 4。若使用裸感測器而非模組，DATA 需加上拉電阻。
