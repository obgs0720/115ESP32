單元 01・硬體控制入門

紅綠燈 LED

讓 ESP32 依序控制紅、黃、綠三盞燈，完成你的第一個交通號誌。

步驟 1・準備材料

開始前先拿好這些零件

ESP32開發板 × 1
LED紅、黃、綠各 × 1
電阻220Ω～330Ω × 3
麵包板跳線若干

步驟 2・接線

每盞燈使用一個 GPIO

LED 的長腳是正極，連到 ESP32 GPIO；短腳經由電阻後接到 GND。每顆 LED 串聯一顆 220Ω～330Ω 電阻。

ESP32GPIO 25GPIO 26GPIO 27GND

紅色 LED：長腳接 GPIO 25

黃色 LED：長腳接 GPIO 26

綠色 LED：長腳接 GPIO 27

三顆 LED：短腳 → 220Ω～330Ω 電阻 → GND

安全提醒：每顆 LED 都要串聯限流電阻，避免損壞 LED 或 ESP32 GPIO。

步驟 3・上傳程式

完整 Arduino 程式

在 Arduino IDE 選擇 ESP32 開發板與正確的序列埠，貼上程式後按上傳。

// ESP32 紅綠燈控制
const int RED_LED = 25;
const int YELLOW_LED = 26;
const int GREEN_LED = 27;

void allOff() {
  digitalWrite(RED_LED, LOW);
  digitalWrite(YELLOW_LED, LOW);
  digitalWrite(GREEN_LED, LOW);
}

void setup() {
  pinMode(RED_LED, OUTPUT);
  pinMode(YELLOW_LED, OUTPUT);
  pinMode(GREEN_LED, OUTPUT);
  allOff();
}

void loop() {
  digitalWrite(GREEN_LED, HIGH);  // 綠燈：通行 5 秒
  delay(5000);
  digitalWrite(GREEN_LED, LOW);

  digitalWrite(YELLOW_LED, HIGH); // 黃燈：注意 2 秒
  delay(2000);
  digitalWrite(YELLOW_LED, LOW);

  digitalWrite(RED_LED, HIGH);    // 紅燈：停止 5 秒
  delay(5000);
  digitalWrite(RED_LED, LOW);
}
