這一頁集中整理輸出、顯示、馬達與無線模組。先用難度找適合的元件，再進入單篇教學補齊接線與程式。

01 / 依程度瀏覽

先從簡單輸出開始

M01 · 簡單GPIO

LED 單色燈

練習數位輸出、限流電阻與 Blink，適合第一個實作。

常見接線
GPIO23 → 220Ω → LED → GND
函式庫
不需外部函式庫
可做應用
狀態燈、警示燈
M02 · 簡單LEDC

RGB LED

把三個顏色通道分別接到 PWM，練習混色與亮度控制。

常見接線
R/G/B → 220Ω → GPIO25/26/27
函式庫
LEDC（ESP32 內建）
可做應用
情境燈、色彩提示
M03 · 簡單LEDC

無源蜂鳴器

用頻率產生音高，從單音延伸成旋律或錯誤提示音。

常見接線
GPIO25 → SIG，VCC／GND 依模組
函式庫
LEDC 或 tone 類 API
可做應用
門鈴、倒數提示
M04 · 中等PWM

SG90 伺服馬達

用 PWM 控制角度，把感測值轉成實際的機械動作。

常見接線
SIG→GPIO13；外部 5V；GND 共地
函式庫
ESP32Servo
可做應用
自動門、指針、雲台
M05 · 中等I2C

0.96 吋 OLED

用兩條 I2C 線顯示文字、數值與簡單圖形。

常見接線
VCC→3V3、GND、SDA→21、SCL→22
函式庫
Wire、Adafruit GFX、SSD1306
可做應用
溫度儀表板、狀態頁
M06 · 中等I2C

LCD1602 I2C

把長文字與多行資訊顯示在液晶螢幕上。

常見接線
SDA→21、SCL→22；供電依模組標示
函式庫
LiquidCrystal_I2C
可做應用
倒數器、環境監控
M07 · 中等PIXEL

WS2812B 彩色燈條

一條資料線控制多顆 RGB LED，開始做燈效與動畫。

常見接線
DIN→GPIO4、5V、GND；資料線建議電阻
函式庫
FastLED 或 Adafruit NeoPixel
可做應用
桌面燈、音樂燈效
M08 · 中等RELAY

單路繼電器

用低電壓 GPIO 控制另一側的負載，認識隔離與安全。

常見接線
IN→GPIO26、VCC／GND 依模組規格
函式庫
不需外部函式庫
可做應用
燈具、風扇、抽水馬達
M09 · 困難STEPPER

28BYJ-48 步進馬達

控制步數與轉速，理解驅動板、步進與位置概念。

常見接線
ULN2003 IN1–IN4→GPIO16–19
函式庫
AccelStepper
可做應用
旋轉平台、窗簾
M10 · 困難SPI

MAX7219 8×8 點矩陣

使用 SPI 類型介面控制大量 LED，練習位元與顯示資料。

常見接線
DIN→23、CLK→18、CS→5、VCC／GND
函式庫
LedControl 或 MD_MAX72XX
可做應用
跑馬燈、簡易字型
M11 · 困難SPI

ILI9341 TFT 觸控螢幕

從單色文字進階到彩色圖形、按鈕與觸控互動。

常見接線
SCK18、MOSI23、MISO19、CS／DC 依設定
函式庫
TFT_eSPI 或 LovyanGFX
可做應用
儀表板、互動遊戲
M12 · 困難CAMERA

ESP32-CAM

整合相機、Wi‑Fi 與記憶卡，進入影像串流與辨識專題。

常見接線
依 ESP32-CAM 型號與相機腳位表
函式庫
esp_camera、WebServer
可做應用
網路攝影機、影像辨識
M13 · 困難WIRELESS

Wi‑Fi / BLE 無線連線

把 ESP32 連到手機、瀏覽器或另一台開發板。

常見接線
無需外部訊號腳位，依專案加裝周邊
函式庫
WiFi、BLE、BluetoothSerial
可做應用
Web Server、手機遙控
使用前提醒

不同板型與模組版本的供電和腳位可能不同；正式教學頁會針對每個型號附上版本、腳位表與接線圖。
