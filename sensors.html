依照資料類型整理常見感應器：從按鈕、光線、溫濕度開始，再進入姿態、聲音、RFID 與 GPS。

先讀取，再思考怎麼應用

S01 · 簡單GPIO

按鈕／微動開關

最基本的數位輸入，學習按下、放開與防彈跳。

常見接線
GPIO27→按鈕→GND，使用 INPUT_PULLUP
函式庫
不需外部函式庫
可做應用
啟動鍵、模式切換
S02 · 簡單ADC

可變電阻

把旋鈕位置轉成類比數值，認識 ADC 讀值。

常見接線
兩端接 3V3／GND，中間腳→GPIO34
函式庫
不需外部函式庫
可做應用
亮度旋鈕、音量控制
S03 · 簡單ADC

光敏電阻 LDR

用分壓電路測量明暗，建立環境感測的第一步。

常見接線
LDR＋10kΩ 分壓，中點→GPIO34
函式庫
不需外部函式庫
可做應用
自動夜燈、亮度告警
S04 · 簡單GPIO

PIR 人體紅外線

偵測移動事件，練習數位訊號與觸發動作。

常見接線
OUT→GPIO27、VCC／GND 依模組
函式庫
不需外部函式庫
可做應用
自動燈、入侵提醒
S05 · 簡單1-WIRE

DHT11 溫濕度

讀取最常見的環境資料，適合搭配序列埠與 OLED。

常見接線
DATA→GPIO4、VCC→3V3、GND
函式庫
DHT sensor library、Adafruit Unified Sensor
可做應用
教室環境監測
S06 · 中等TIME

HC-SR04 超音波

由 Trig 發送、Echo 接收回波，計算物體距離。

常見接線
Trig→GPIO5；Echo→GPIO18 需降壓
函式庫
不需外部函式庫或 NewPing
可做應用
倒車雷達、避障車
S07 · 中等1-WIRE

DS18B20 防水溫度

用單線匯流排連接一顆或多顆溫度探頭。

常見接線
DATA→GPIO4，DATA 與 3V3 間加 4.7kΩ
函式庫
OneWire、DallasTemperature
可做應用
水溫、土壤溫度
S08 · 中等ADC

土壤濕度

讀取介質濕度，並注意電極腐蝕與供電電壓。

常見接線
AO→GPIO34、VCC／GND；不要直接輸入 5V
函式庫
不需外部函式庫
可做應用
自動澆水、盆栽監控
S09 · 中等ADC

MQ-2 瓦斯／煙霧

以類比值觀察氣體濃度變化，先做相對量測。

常見接線
AO→ADC，模組輸出超過 3.3V 時需分壓
函式庫
不需外部函式庫
可做應用
環境警示、煙霧變化
S10 · 中等I2C

MPU6050 姿態

讀取加速度與陀螺儀，開始理解角度和動態資料。

常見接線
SDA→21、SCL→22、VCC→3V3、GND
函式庫
Wire、Adafruit MPU6050
可做應用
搖桿、計步、姿態控制
S11 · 中等I2C

BME280 氣壓環境

同時量測溫度、濕度與氣壓，適合製作環境儀表。

常見接線
SDA→21、SCL→22；I2C 位址依模組
函式庫
Adafruit BME280、Wire
可做應用
氣象站、樓層高度估算
S12 · 困難I2C

BH1750 光照度

用標準單位 lux 讀取環境亮度，適合自動調光。

常見接線
SDA→21、SCL→22、VCC→3V3、GND
函式庫
BH1750
可做應用
智慧照明、植物燈
S13 · 困難SPI

RC522 RFID

讀取卡片 UID，練習 SPI 腳位與門禁邏輯。

常見接線
SCK18、MOSI23、MISO19、SDA/SS5、RST27
函式庫
MFRC522
可做應用
簽到、門禁、借閱
S14 · 困難I2S

INMP441 數位麥克風

用 I2S 取樣聲音，進一步做音量、頻譜或串流。

常見接線
BCLK→26、WS→25、SD→33、3V3／GND
函式庫
ESP32 I2S API
可做應用
聲控、即時音訊
S15 · 困難UART

NEO-6M GPS

接收經緯度與時間資料，練習第二組 UART。

常見接線
GPS TX→ESP32 RX16；GPS RX→TX17
函式庫
TinyGPSPlus
可做應用
定位、軌跡記錄
S16 · 困難SPI

AS608 指紋模組

從 UART 指令進入資料庫、比對與權限管理。

常見接線
模組 TX/RX 接 ESP32 UART，供電依模組
函式庫
Adafruit Fingerprint Sensor
可做應用
指紋門禁、身分辨識
S17 · 困難UART

光學心率感測器

讀取脈搏與血氧類資料，適合用來練習資料清理。

常見接線
I2C 或 UART，依 MAX30102 模組版本
函式庫
MAX30105 / MAX3010x 系列函式庫
可做應用
生理資料展示
安全提醒

ESP32 GPIO 不可直接承受 5V。HC-SR04、MQ-2、LCD 與其他模組的供電和訊號電壓，必須先看模組版本與資料表。
