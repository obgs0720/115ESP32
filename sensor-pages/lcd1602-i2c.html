02 / 模組介紹

LCD1602 I2C 是什麼？

LCD1602 是每行 16 個字、共 2 行的字元型液晶顯示器。加上 I2C 背板後，原本需要許多平行控制線，現在主要只要使用 SDA、SCL、VCC 與 GND。

I2C 背板通常使用 PCF8574 I/O 擴充晶片，把 ESP32 的 I2C 指令轉成 LCD1602 可以理解的控制訊號。常見 I2C 位址是 0x27，另一部分模組會使用 0x3F。

實際位址、供電與背光亮度會依模組版本不同；如果畫面完全沒有文字，第一個要檢查的就是 I2C 位址與對比度旋鈕。

16×2每行 16 字、共 2 行
I2CSDA／SCL 兩條資料線
0x27最常見的模組位址
PCF8574常見 I/O 擴充晶片
5V / 3.3V依模組規格供電

03 / 開發平台

NodeMCU-32S 腳位設定

本教學使用 NodeMCU-32S，I2C 的預設腳位是 SDA＝GPIO21、SCL＝GPIO22。程式仍會明確呼叫 Wire.begin(21, 22)，讓接線與程式一眼就能對照。

第二個範例將 DHT11 的 DATA 接到 GPIO4。LCD 與 DHT11 必須和 NodeMCU-32S 共用 GND，否則資料可能讀取失敗或畫面不穩定。

本教學使用的腳位LCD SDA → GPIO21LCD SCL → GPIO22LCD VCC → 3V3（入門安全接法）LCD GND → GNDDHT11 DATA → GPIO4

04 / 接腳說明

先認識兩個模組的接腳

LCD1602 I2C 背板

背板上通常會標示四個接腳。不同廠牌的排列方向可能不同，請以板上的 VCC、GND、SDA、SCL 絲印為準。

GNDVCCSDASCL

VCC 是電源、GND 是接地、SDA 傳送資料、SCL 提供 I2C 時脈。

DHT11 三腳位模組

本範例使用已焊接上拉電阻的三腳位 DHT11 模組，通常會標示 VCC、DATA、GND。若是四腳裸感測器，DATA 與 3.3V 之間需要另外加 4.7kΩ～10kΩ 上拉電阻。

VCCDATAGND

DHT11 建議至少間隔 1～2 秒讀取一次，不能在迴圈中高速連續讀取。

07 / 第一個範例

先顯示 Hello

這個版本只測試 LCD，不接 DHT11。確認畫面能顯示後，再進入下一個完整的溫濕度範例。

Arduino / LCD1602 I2C / Hello
#include <Wire.h>
#include <LiquidCrystal_I2C.h>

// 常見 I2C 位址是 0x27；若無法顯示，可改試 0x3F
#define LCD_ADDRESS 0x27
#define LCD_COLUMNS 16
#define LCD_ROWS 2

LiquidCrystal_I2C lcd(LCD_ADDRESS, LCD_COLUMNS, LCD_ROWS);

void setup() {
  // NodeMCU-32S：SDA = GPIO21，SCL = GPIO22
  Wire.begin(21, 22);

  lcd.init();
  lcd.backlight();
  lcd.clear();

  lcd.setCursor(0, 0);
  lcd.print("Hello");
  lcd.setCursor(0, 1);
  lcd.print("ESP32S + LCD");
}

void loop() {
  // Hello 範例不需要重複更新
}

LiquidCrystal_I2C lcd(0x27, 16, 2) 建立一個 16 欄、2 列的 LCD 物件；如果你的背板位址是 0x3F，請把 0x27 改成 0x3F。

setCursor(欄, 列) 的欄與列從 0 開始。setCursor(0, 0) 是左上角，setCursor(0, 1) 是第二行左側。

08 / 空白畫面排除

如果 Hello 沒有出現

先確認 LCD 背板上的對比度旋鈕。螢幕有背光但沒有字，常常只是對比度太低或太高。接著確認 SDA、SCL 沒有接反，並檢查程式中的 I2C 位址。

若仍找不到位址，可以先執行 I2C Scanner。序列埠監控視窗若顯示 0x27 或 0x3F，就把那個位址填回完整範例。

10 / 完整範例

顯示目前溫度與濕度

這個程式同時使用 I2C LCD1602 與 DHT11。每兩秒讀取一次 DHT11，並把資料更新到 LCD 與序列埠監控視窗。

Arduino / LCD1602 I2C + DHT11
#include <Wire.h>
#include <LiquidCrystal_I2C.h>
#include <DHT.h>

#define SDA_PIN 21
#define SCL_PIN 22
#define DHT_PIN 4
#define DHT_TYPE DHT11
#define LCD_ADDRESS 0x27   // 無畫面時可改試 0x3F

LiquidCrystal_I2C lcd(LCD_ADDRESS, 16, 2);
DHT dht(DHT_PIN, DHT_TYPE);

void setup() {
  Serial.begin(115200);

  // NodeMCU-32S 的 I2C 腳位
  Wire.begin(SDA_PIN, SCL_PIN);

  lcd.init();
  lcd.backlight();
  lcd.clear();

  dht.begin();

  lcd.setCursor(0, 0);
  lcd.print("ESP32S + DHT11");
  lcd.setCursor(0, 1);
  lcd.print("Starting...");
  delay(1500);
}

void loop() {
  // DHT11 不適合高速連續讀取，至少間隔 1～2 秒
  float humidity = dht.readHumidity();
  float temperature = dht.readTemperature();

  if (isnan(humidity) || isnan(temperature)) {
    Serial.println("DHT11 讀取失敗，請檢查接線！");
    lcd.clear();
    lcd.setCursor(0, 0);
    lcd.print("DHT11 Error");
    lcd.setCursor(0, 1);
    lcd.print("Check wiring");
  } else {
    Serial.print("Temperature: ");
    Serial.print(temperature, 1);
    Serial.print(" C | Humidity: ");
    Serial.print(humidity, 1);
    Serial.println(" %");

    lcd.clear();
    lcd.setCursor(0, 0);
    lcd.print("T:");
    lcd.print(temperature, 1);
    lcd.write(byte(223));  // LCD 的度數符號
    lcd.print("C H:");
    lcd.print(humidity, 1);
    lcd.print("%");

    lcd.setCursor(0, 1);
    lcd.print("NodeMCU-32S");
  }

  delay(2000);
}

Wire.begin(21, 22) 指定 I2C 的 SDA 與 SCL。DHT dht(4, DHT11) 則表示 DHT11 DATA 接在 GPIO4。

如果 LCD 沒有畫面，先掃描 I2C 位址，再修改 LCD_ADDRESS。如果 LCD 正常但出現 DHT11 Error，請優先檢查 DATA、VCC、GND 與函式庫是否安裝完成。

11 / 觀察結果

LCD 與序列埠會看到什麼？

上傳程式後，開啟 Arduino IDE 的序列埠監控視窗，鮑率設定為 115200。LCD 第一行會顯示溫度與濕度，第二行顯示目前使用的開發板。

Temperature: 25.0 C | Humidity: 62.0 %
Temperature: 25.0 C | Humidity: 63.0 %

DHT11 的解析度通常是 1°C 與 1%RH，因此畫面上的小數常常會是 .0；這不是 LCD 的問題，而是感測器本身的解析度限制。

12 / 問題排除

常見問題與排除方法

LCD 背光亮但沒有文字

調整背板上的對比度旋鈕；再確認 LCD 位址是 0x27 還是 0x3F，並確認 SDA、SCL 沒有接反。

畫面出現亂碼

檢查供電是否穩定、GND 是否共地，並確認程式的欄數與列數是 16、2。使用 5V LCD 時，請處理 I2C 電位相容問題。

DHT11 顯示 Error

確認 DHT11 DATA 接 GPIO4、VCC 接 3V3、GND 共地；檢查 DHT sensor library 與 Adafruit Unified Sensor 是否都已安裝。

數值更新很慢

DHT11 本身不適合快速取樣，本範例每兩秒更新一次是正常的。需要更快或更精準時，可改用 DHT22、AHT20 或 BME280。

LCD 顯示超出範圍

每一行最多 16 個字元。若文字太長，請縮短字串，或使用 lcd.setCursor() 分行顯示。

上傳程式失敗

確認已選 NodeMCU-32S、正確的 COM Port，必要時按住 BOOT 鍵直到 Arduino IDE 開始上傳。
