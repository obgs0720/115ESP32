02 / 最小範例

先讓 LED 閃爍

這段程式是所有實作的起點：先設定腳位，再在 loop() 裡重複控制輸出。

  1. const int 把腳位名稱固定下來。
  2. pinMode 指定腳位是輸入或輸出。
  3. digitalWrite 輸出 HIGH 或 LOW。
01_led_blink.ino簡單
// GPIO 23 接外部 LED
const int LED_PIN = 23;

void setup() {
  pinMode(LED_PIN, OUTPUT);
}

void loop() {
  digitalWrite(LED_PIN, HIGH);
  delay(1000);
  digitalWrite(LED_PIN, LOW);
  delay(1000);
}

03 / GPIO

輸入和輸出是兩種不同的角色

按鈕、PIR 等元件通常提供輸入；LED、繼電器等元件接收輸出。教學中會先畫出訊號方向，再寫程式。

INPUTdigitalRead / analogRead
OUTPUTdigitalWrite / ledcWrite
注意ESP32 GPIO 邏輯通常是 3.3V

04 / ADC + PWM

把讀到的數值轉成動作

例如用可變電阻讀取 0–4095，再將數值換算為 LEDC 的亮度。這是「感測器 → 控制器 → 輸出」的基本模式。

02_adc_to_pwm.ino中等
const int KNOB = 34;
const int LED = 23;

void setup() {
  ledcAttach(LED, 5000, 8);
}

void loop() {
  int value = analogRead(KNOB);
  int duty = map(value, 0, 4095, 0, 255);
  ledcWrite(LED, duty);
}
